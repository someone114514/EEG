# EEG Research Workspace

这是 EEG 研究项目的总览入口，用于集中保存项目说明、代码、配置、运行记录、结果和可复现性材料。

## 项目入口

```text
C:\Users\User\Documents\Codex\2026-08-03\du-q
```

WSL 环境下对应的项目目录为：

```text
/root/b_false_alarm_atlas
```

## 目录导航

- `docs/`：项目说明、方法记录与文档
- `scripts/`：数据处理、运行和分析脚本
- `configs/`：实验配置与参数
- `outputs/`：结果、表格、图像和报告
- `logs/`：运行日志与状态记录
- `manifests/`：数据、划分、版本和审计清单

## 使用原则

优先查看最新的 `README`、`manifest` 和 `audit` 文件；保留历史版本，不覆盖已有结果。任何正式结果都应能够追溯到对应的代码、配置、数据划分和运行日志。
